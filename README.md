# SK Fashion — WooCommerce Clothing Store Theme

A fully custom WooCommerce clothing store built from scratch for portfolio demonstration.

## 🛍️ Features

- **Custom WordPress Theme** — no page builders, pure PHP/HTML/CSS/JS
- **WooCommerce Integration** — full e-commerce functionality
- **Shop Page** — sidebar categories, product grid, sale badges, hover effects
- **Single Product Page** — image, quantity selector, Add to Cart, Buy Now
- **Cart & Checkout** — custom styled, Cash on Delivery payment
- **Order Confirmation** — clean thank you page with order summary
- **4 Categories** — Men, Women, Kids, Sale
- **Responsive Design** — mobile and desktop

## 🛠️ Technologies

| Technology | Usage |
|---|---|
| WordPress | CMS & Backend |
| WooCommerce | E-Commerce Engine |
| PHP | Custom Templates |
| CSS | Custom Design System |
| JavaScript | Interactions & Animations |
| LocalWP | Local Development |

## 📁 Theme Files

```
sk-store-theme/
├── style.css           # Design system + all CSS
├── functions.php       # WooCommerce support & enqueues
├── header.php          # Sticky header with cart icon
├── footer.php          # Newsletter + 4-column footer
├── index.php           # Homepage (hero, categories, products)
├── woocommerce.php     # Master WC template (shop/product/cart)
├── page.php            # Cart/Checkout/My Account pages
└── assets/
    └── js/main.js      # Animations & interactions
```

## 🚀 Setup

1. Install WordPress + WooCommerce
2. Copy `sk-store-theme/` to `wp-content/themes/`
3. Activate theme in WP Admin → Appearance → Themes
4. Go to WooCommerce → Settings → Configure pages & currency
